# Code of conduct

This project welcomes contributions from anyone, and it expects everyone taking part to act with
respect and good faith.

## Expected behaviour

Be civil and constructive, and assume competence and good intent in others. Focus criticism on
code, evidence, and arguments, and keep it specific and actionable. The maintainer carries final
responsibility for a contract that moves real money, so a conservative decision on security is the
default.

## Unacceptable behaviour

Harassment, personal attacks, discriminatory or demeaning comments, and sustained disruption are
not tolerated. Publishing another person's private information without consent is not tolerated.
Deliberately introducing insecure or malicious code is both a conduct violation and a security
matter.

## Scope

This applies in the repository's issues, pull requests, and any other project space, and to
conduct outside those spaces when it affects the project or its participants.

## Enforcement

Report a concern to the maintainer through GitHub, where it is handled confidentially. The
maintainer may remove comments, reject contributions, or block an account for behaviour that
violates this policy, in proportion to the matter.
